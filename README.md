# ごみの向こう側 ― 出前授業アプリ（講師用マニュアル）

小学4年生むけ 出前授業「みんなの暮らしを支える仕事 ～ごみの向こう側を知ろう～」で
教室のプロジェクターに映して使う、参加型アプリです。

- **インターネットはいりません**（機内モード・LANケーブルを抜いた状態でも動きます）
- **インストール不要**。`index.html` をダブルクリックするだけです
- 操作するのは講師だけ。児童は手をあげて答えます

---

## 1. 開き方（3ステップ）

1. `shibetsu-lesson-app` フォルダを、ノートPCのデスクトップなどにコピーします。
2. フォルダの中の **`index.html`** をダブルクリックします。
3. Microsoft Edge または Google Chrome が立ち上がり、トップ画面が出れば成功です。

> **うまく開かないとき**
> `index.html` を右クリック →「プログラムから開く」→「Microsoft Edge」を選んでください。

**プロジェクターに映すとき**
Windowsキー ＋ P を押して「複製」または「拡張」を選びます。
アプリの画面右下の **⛶ ボタン**（またはキーボードの **F**）で全画面になります。
全画面をやめるときは、もう一度 **F** か **Esc**（ブラウザによっては F11）です。

**音について**
最初のクリックまたはキー操作をしたときから音が鳴ります。
音を消したいときは画面右下の **🔊 ボタン**、またはキーボードの **M** です。

---

## 2. 授業での使い方（おすすめの流れ）

| 授業の場面 | 使う画面 |
|---|---|
| つかみ・ごみの分別の話 | ① ごみの ぶんべつクイズ |
| もしこの仕事がなくなったら？ | ③ ごみを あつめよう（2つのモード） |
| 士別のこれからの話 | ④ 士別の 人の数 |
| 仕事を選ぶとき何を大切にしたい？ | ② みんなの とうひょう |

トップ画面の大きなボタンを押すか、キーボードの **1・2・3・4** で各画面に入ります。
どの画面からも **Esc** でトップ画面にもどれます。

---

## 3. 各画面の使い方

### ① ごみの ぶんべつクイズ

1. 問題（ごみの名前と絵）が大きく出ます。
2. **「スタート（10びょう）」**（キーボードは **Space**）を押すと 10秒のカウントダウンが始まります。
   この間に「〇〇だと思う人？」と聞いて、児童に手をあげてもらいます。
3. 手をあげた人数を入力します。方法は2つ。
   - 画面の選択肢をクリック（または ＋ / − ボタン）
   - キーボードの **1〜4**（押すたびに ＋1）／ **Shift + 1〜4** で −1
4. **「せいかい はっぴょう」**（キーボードは **Enter**）を押すと、ドラムロールのあと
   正解が光り、紙吹雪と音が出ます。正解した人数と、1行の解説も出ます。
5. **「つぎの もんだい」**（**Space**）で次へ。最後の問題のあとは
   **「けっかを みる」** で、全6問の正解者数の棒グラフが出ます。
   「クラス みんなで ○○人 せいかい！」とみんなをほめる画面です（個人の順位は出ません）。

> 間違えて数を入れたときは「0に もどす」で入れ直せます。
> 発表のあとに「まえの もんだい」で1問もどることもできます。

### ② みんなの とうひょう

- 6つの項目に、手をあげた人数を入れると、横棒グラフがのびます。
- 入力は項目をクリック、＋ / − ボタン、またはキーボードの **1〜9**。
- 「せいかいは ありません」という一文が、いつも画面に出ています。
- 児童から出た意見は、下の入力らんに文字を打って **「ふやす」** を押すと、
  その場で項目として追加されます（そのとき 1人 として数えます）。
- 「0に もどす」で人数をリセットできます（追加した項目は残ります）。

### ③ ごみを あつめよう（パッカー車ミニゲーム）

- **「スタート」**（**Space**）で30秒のゲームが始まります。
- **← → キー**（またはマウスを画面の上で左右に動かす／クリック）でパッカー車が動きます。
- 画面の上に出ている **「いま あつめるのは ○○」** と同じごみだけが点数になります。
  ちがうごみを取っても減点はなく、「ちがうよ！」と出るだけです。
- 30秒たつと「○個 あつめました！」と出ます。児童を1〜2人前に呼んで操作させてもOKです。
- **「もし ごみを あつめる人が いなかったら」** ボタンを押すと、
  15秒間、車が動かずごみが積み上がるだけの画面になり、
  最後に「まちが ごみで いっぱいに…」と出ます。ここで児童に問いかけてください。

### ④ 士別の 人の数

- **「スタート」**（**Space**）を押すたびに、人数が
  20,000人（2016年）→ 15,988人（2026年）→ 8,000人（2050年 予想）と
  アニメーションで減っていきます。人のマーク（1つ＝100人）も消えていきます。
- 最後に「人が すくなくなると、どんなことが こまるかな？」の問いが出ます。
- 「はじめに もどす」で何度でもやり直せます。

## 4. キーボード操作の一覧

画面右下の **？ ボタン**（またはキーボードの **H**）でも同じ一覧が出ます。

| キー | はたらき |
|---|---|
| **Esc** | トップ画面にもどる（ヘルプを閉じる） |
| **Space** | スタート／つぎへすすむ |
| **1〜4** | クイズ：えらんだ人の数を ＋1 ／ トップ画面：メニューを開く |
| **Shift + 1〜4** | クイズ：数を −1 |
| **1〜9** | とうひょう：その項目を ＋1 |
| **Enter** | クイズ：正解発表 |
| **← →** | ゲーム：パッカー車を動かす |
| **M** | 音の ON / OFF |
| **F** | 全画面にする／もどす |
| **H** または **？** | ヘルプを開く |

プレゼン用リモコンの多くは「次へ＝Space」「戻る＝←」なので、
リモコンだけでもクイズを進行できます。

---

## 5. うっかりリロードしてしまったら

クイズの進行状況（何問目か・入力した人数）は自動でパソコンに保存されています。
画面を閉じたり更新したりしても、もう一度 `index.html` を開けば
トップ画面に **「前回の つづきから（第○もん）」** ボタンが出ます。

次のクラスで最初からやり直すときは、その横の **「きろくを けす」** を押してください。

## 6. 問題を差しかえる（士別市のルールに合わせる）

> **重要**：初期データの答えは「仮」です。
> 実際の授業前に、士別市の分別区分で必ずご確認のうえ書きかえてください。

### 手順

1. `index.html` を右クリック →「プログラムから開く」→ **「メモ帳」** を選びます。
2. ファイルのいちばん上（10行目あたり）に
   `★★★ ここだけ 書きかえれば 中身を かえられます（DATA） ★★★`
   という行があります。ここから `DATA ここまで` の行までが編集する場所です。
   （見つからないときは、メモ帳の「編集」→「検索」で `★★★` と入力してさがせます）
3. 書きかえたら、メモ帳の「ファイル」→「上書き保存」。
4. ブラウザにもどって **F5**（更新）を押すと、新しい内容になります。

### 書きかえる場所

**(1) 分別の区分（選択肢）**

```
choices: [
  { key: "moyaseru",  label: "もやせるごみ",   color: "#F28B30" },
  { key: "moyasenai", label: "もやせないごみ", color: "#2F80C3" },
  { key: "shigen",    label: "しげんごみ",     color: "#2E9E5B" },
  { key: "kiken",     label: "きけんごみ",     color: "#D9534F" }
],
```

- `label:` のうしろの「もやせるごみ」などが、画面に出る文字です。ここを書きかえます。
- `key:` は目印なので、そのままにしておくのが安全です（変えるときは下の `answer:` も同じ言葉に）。

**(2) 問題**

```
{ name:"ペットボトル", emoji:"🧴", image:"", answer:"shigen",
  tip:"キャップと ラベルは はずして、中を 水で あらってね" },
```

| 書く場所 | 意味 |
|---|---|
| `name:` | 画面に大きく出るごみの名前 |
| `emoji:` | 絵文字（写真を使わないときの絵） |
| `image:` | 写真のファイル名（次の項目を参照。使わないときは `""` のまま） |
| `answer:` | 正解。上の `key:` の言葉のどれかを書きます |
| `tip:` | 正解の下に出る1行の解説 |

問題をふやすときは、`{ ... },` の1行のかたまりをコピーして、下に貼りつけて書きかえます。
へらすときは、その1かたまりを削除します。

**(3) 手をあげる時間**　`countdownSeconds: 10` の数字（秒）を変えます。

### 気をつけること

- `"` （ダブルクォート）を消さないでください。文字は必ず `"` ではさみます。
- 行の終わりの `,`（カンマ）も消さないでください。
- 保存するときは、メモ帳の「名前を付けて保存」で **文字コード＝UTF-8** を選びます
  （上書き保存ならそのままで大丈夫です）。
- 心配なときは、書きかえる前に `index.html` をコピーして
  `index_バックアップ.html` などの名前で残しておくと安心です。

## 7. 写真に差しかえる

絵文字のかわりに、実際のごみの写真を出せます。

1. 写真（jpg または png）を、この中の **`images` フォルダ**に入れます。
   例：`images/pet.jpg`
2. `index.html` をメモ帳で開き、その問題の `image:""` を
   `image:"images/pet.jpg"` のように書きかえます。
3. 保存してブラウザを **F5** で更新すると、写真が出ます。

- ファイル名は **半角英数字**（例：`pet.jpg`, `danball.png`）にしてください。
- 写真は正方形に近いものがきれいに出ます（目安：600×600ピクセル程度）。
- 写真が見つからないときは、自動で絵文字にもどるので授業は止まりません。

## 8. とうひょう項目・人口の数字を変える

同じ `DATA` の中にあります。

**とうひょうの項目**

```
vote: {
  question: "しごとで 大切に したいことは？",
  options: [
    { label:"人の 役に立ちたい", color:"#2E9E5B" },
    ...
  ]
},
```

`label:` の文字を書きかえます。項目をふやす・へらすのも問題と同じやり方です。

**人口の数字**

```
population: {
  perIcon: 100,
  steps: [
    { year:"2016年",         value:20000, note:"" },
    { year:"2026年（いま）",  value:15988, note:"" },
    { year:"2050年（よそう）", value:8000,  note:"" }
  ],
  finalQuestion: "人が すくなくなると、どんなことが こまるかな？"
}
```

- `year:` が画面に出る年、`value:` が人数です（数字にカンマは入れません）。
- `perIcon: 100` は「人のマーク1つ＝何人ぶんか」です。

**ミニゲームの時間**

```
game: {
  playSeconds: 30,     ← あそぶ時間（秒）
  watchSeconds: 15,    ← 「あつめる人がいなかったら」の時間（秒）
```

## 9. こまったときは

| こまりごと | 対処 |
|---|---|
| 音が出ない | 画面を1回クリックしてから操作してください。右下が 🔇 になっていたら押して 🔊 に |
| 文字が小さい | **F** で全画面にしてください。ブラウザの拡大（Ctrl + ＋）でも大きくなります |
| キーが効かない | 画面のどこかを1回クリックしてから、もう一度キーを押してください |
| 画面がずれる | ブラウザの拡大率を 100%（Ctrl + 0）にもどしてください |
| スマホで見たい | スマホやタブレットでも開けます（画面の大きさに合わせて自動で切りかわります）。ただし下見用です。授業本番は必ずパソコンで、ネット接続なしで使ってください |
| 書きかえたら動かなくなった | バックアップにもどすか、`"` や `,` の消し忘れがないか確認してください |
