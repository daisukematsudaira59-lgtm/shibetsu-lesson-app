# かぶナビAI

**初心者でも3分でわかる株式投資分析**

「どの株を調べればいいのか」「この株は買っていいのか」「なぜその判断なのか」に、
初心者が一目で答えられることを目指した株式投資分析アプリの MVP です。

> ⚠️ **現在はデモ（サンプルデータ）で動作しています。**
> 画面上の株価・財務数値はすべて UI 検証用のサンプルであり、実在企業の実際の数値ではありません。
> 実データが接続されるまで、この警告はアプリ内の全画面に表示されます。

---

## 使い方

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # 本番ビルド
npm run preview  # ビルド結果の確認
```

スマートフォン幅（390px 前後）を基準に設計しています。PC でも表示できます。

## このアプリの立ち位置

- **投資助言ではなく情報分析ツール**です。「絶対上がる」「必ず儲かる」「買うべき」といった断定は行いません。
- 分析結果は「分析上は○○」「この点が強み」「この点には注意」という形式で示し、**最終判断は利用者本人**に委ねます。
- SBI証券の **ログインID・パスワードは一切扱いません**。「SBI証券で調べる」という外部リンクの導線のみを提供します。
- 「SBI証券 株アプリ」「HYPER SBI 2」の代替ではなく、**初心者の分析・学習支援**に特化しています。

## 設計方針：データ・分析・解説・UI の分離

将来 API を差し替えても全面的な作り直しにならないよう、4層に分離しています。

```
src/
├── types/stock.ts        ドメイン型（各層の共通契約）
├── data/                 ① データ取得
│   ├── provider.ts         StockDataProvider インターフェース
│   ├── index.ts            ★ ここを差し替えるだけで実データに移行できる
│   └── mock/               デモ用サンプルデータ（実データ接続時は削除可）
├── analysis/             ② 分析ロジック（純粋関数。UI に依存しない）
│   ├── indicators.ts       SMA / RSI / MACD
│   ├── score/              業績・財務・割安度・成長性・配当・チャートの採点
│   ├── total.ts            100点満点への合成と整合性チェック
│   ├── warnings.ts         注意ポイントの検出
│   ├── priceBands.ts       参考レンジ
│   ├── timing.ts           買い時の3パターン比較
│   └── screening.ts        ホーム / ランキング / 予算別
├── explain/              ③ AI解説（数値 → 日本語）
│   ├── summary.ts          一言まとめ・3行まとめ
│   ├── news.ts             ニュース分類と平易な言い換え
│   ├── earnings.ts         決算評価
│   ├── preBuy.ts           買う前の確認項目・チェックリスト
│   └── glossary.ts         用語辞典
└── ui/                   ④ UI（分析結果を表示するだけ）
```

UI は `analyze(stock)` が返す `StockAnalysis` だけを参照しており、データ提供元を知りません。

### 実データを接続するには

1. `StockDataProvider`（`src/data/provider.ts`）を実装したクラスを作る
2. `src/data/index.ts` の `provider` を差し替える
3. `DataMeta.isDemo` を `false`、`sourceName` / `asOf` / `notice` を実際の値にする

分析ロジック・解説文・UI の変更は不要です。

接続前に**必ず**確認してください（要件23）：
提供元 / 利用規約 / 商用利用可否 / 再配布可否 / 更新頻度 / 遅延・リアルタイム性 / 呼び出し制限 / 料金。
確認結果は `DataMeta.notice` に入れると全画面に表示されます。

## 投資判断ルール（要件27の実装）

単一の指標だけで高評価・低評価にならないようにしています。

- **配点**：業績 20 / 財務 20 / 割安度 20 / 成長性 20 / 配当 10 / チャート 10 ＝ 100点
- **整合性チェック**（`analysis/total.ts` の `crossCheck`）が、次のような組み合わせを検出して減点し、
  理由を画面に表示します。
  - 割安だが業績が弱い → 「安い理由が業績の弱さかもしれません」（バリュートラップ）
  - 株価は上昇しているが業績が追いついていない
  - 高利回りだが配当性向が高い／過去に減配している
  - 割高なのに成長が限定的
  - 財務と業績の両方に不安
- **データ不足時は点数を付けません。**「判断材料不足」と表示します
  （欠損項目は満点計算から除外し、必須3項目のうち2つ以上が欠ける、または取得率が60%未満の場合）。

## リスク管理（要件28の実装）

- 情報分析ツールである旨を初回起動時のモーダルと各画面に表示
- 将来の利益を保証しない旨、ルールベースの分析である旨を明示
- **データ取得時点を全画面に表示**し、24時間以上経過している場合は警告
- データがない場合は推測せず「ー」「判断材料不足」と表示
- 証券会社の認証情報を保存する仕組みを持たない

## 技術構成

React 18 + TypeScript + Vite。ランタイム依存は React のみで、チャートは自前の SVG 実装です。
お気に入り・チェックリスト・初心者モードの設定は localStorage に保存します（サーバー送信なし）。
